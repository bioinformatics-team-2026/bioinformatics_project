FASTQ Dataset Preparation for Disease Classification

Project Purpose

This project prepares miRNA-Seq FASTQ datasets for binary classification between healthy control samples and Type 2 Diabetes patients using bioinformatics and machine learning techniques.



Class 0: Healthy Control Samples

Class 1: Type 2 Diabetes Samples



Quick Start

python -m venv bioinfo\_env

bioinfo\_env\\Scripts\\activate

pip install -r requirements.txt
